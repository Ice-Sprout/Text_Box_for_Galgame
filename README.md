# Text_Box_for_Galgame

一个将文本转换为类似Galgame对话风格图片的程序，支持自定义。

> 本项目灵感来源于 [manosaba_text_box](https://github.com/oplivilqo/manosaba_text_box)，代码基于 [Text_box-of-mahoushoujo_no_majosaiban-NEO](https://github.com/morpheus315/Text_box-of-mahoushoujo_no_majosaiban-NEO) 这一二次编辑版本，并使用了deepseek辅助编写代码。图像功能支持的debug源自[wyx8949804162006](https://gitcode.com/wyx8949804162006) 。

## ✨ 功能特色

- **🎨 Galgame风格对话生成**：将普通文本转换为具有Galgame风格的对话图片
- **😊 自定义角色与多表情支持**：支持为不同角色配置多种表情，丰富对话表现
- **🖼️ 自定义背景**：可自定义对话背景，适配不同场景
- **⌨️ 热键实时处理**：通过热键快速触发文本处理和图片生成
- **🔣 LaTeX公式支持**：支持在文本中嵌入简单的LaTeX公式
- **📝 自动文本适配与格式化**：文本自动适应对话框并进行美观排版

## 运行方法

安装requrements中相关依赖后，运行resource_manager.py，进行背景图像和角色表情的导入。

背景图像需要导入背景图片和一张透明图像框，创建文件夹除名字外正常保持初始值即可。角色需要15张表情，背景图像无数量限制。角色首个字的颜色可通过设置角色颜色修改。角色设置完成后需要在界面第三栏保存为info.py文件。（现有背景为个人所摄图片，表情为网上找到的杏铃表情包，仅作案例参考）

然后运行gui.py文件，先选择角色和背景进行预生成，然后按全局热键对应的快捷键进行运行。如果需要使用api读取文本进行情绪-表情选择功能，在api一栏输入你的key。现用版本为deepseekchat。注意进行各项设置和切换后需要先保存一下设置。

## 注意事项

main.py尚未进行相关改动,因此大概率不能正常运行,有进行废弃的打算。

如使用api读取文本进行情绪-表情选择功能，建议15张表情分别为1-平静, 2-开心, 3-惊讶, 4-气恼, 5-看乐子/开玩笑, 6-伤心, 7-尴尬, 8-慌乱, 9-卖萌, 10-认真, 11-疲劳/鄙夷, 12-疑惑, 13-悲伤, 14-哭泣, 15-愤怒，这是出于api所使用的提示词限制，可在api.py中修改。当前版本如果无api选择自动则仅会输出默认表情。

背景图不要太扁，表情图需要为方形或者瘦高的。如果预生成时得到的脑袋比较小，就把宽裁剪小一点，或者调整放大倍数enlarge（以750像素宽度为基础的放大倍数）和位置参数drawx和drawy（单位为像素）。若表情位置不对,可通过drawx和drawy的值进行调整。如果并非所有表情都有相同问题，不建议调整放大倍数enlarge和位置参数drawx和drawy，因为这一方式对所有表情都有影响。

由于latex实现依靠latex转unicode而不是转为matplotlib渲染实现，很多功能受限，比如下标x等无法实现，且只能为单行，不支持多行公式。除法请使用/，暂不支持\frac{}{}转为“/”。

暂不支持文字与图片一起发送，一起发送只能发送文字。

由于添加过压缩功能，一张图约100kb，大致为一张表情包大小。不过由于qq会自动下载图像，最终依旧比直接发送文本大很多，注意节制。
