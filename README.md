# 星白对话框

一个将文本转换为类似galgame对话框风格图片的程序。

> 本项目灵感来源于 [manosaba_text_box](https://github.com/oplivilqo/manosaba_text_box)，代码基于 [Text_box-of-mahoushoujo_no_majosaiban-NEO](https://github.com/morpheus315/Text_box-of-mahoushoujo_no_majosaiban-NEO) 的二次编辑版本，并使用了deepseek与ChatGPT辅助编写代码。

## ✨ 功能特色

- **🎨 Galgame风格对话生成**：将普通文本转换为具有星白对话框风格的对话图片
- **😊 多角色与多表情支持**：支持为不同角色配置多种表情，丰富对话表现
- **⌨️ 热键实时处理**：通过热键快速触发文本处理和图片生成
- **🔣 LaTeX公式支持**：支持在文本中嵌入简单的LaTeX公式
- **📝 自动文本适配与格式化**：文本自动适应对话框并进行美观排版
- **🖥️ 双界面可选**：提供图形用户界面(GUI)和命令行界面供用户选择
- **🛠️ 自定义功能支持**：资源管理器可协助进行角色、背景的导入和配置
- **🧠 文本情绪识别功能**：使用DeepSeek API识别文本情绪并自动选择对应表情

## ⚠️ 注意事项

### 基本使用

- 每个角色使用前需点击**预生成**按钮，生成完毕后方可使用。提前按 Enter 键可能导致Bug，需清空图片重新预生成。已有预生成图片则无需再次生成。
- 切换角色或更改快捷键等操作后，需点击**保存设置**才能生效。
- 为方便日常使用，`星白对话框.exe` 默认最小化到系统托盘，右键点击托盘图标可打开窗口或退出程序。

### 配置文件与API

- `info.json` 涉及API Key，未包含在源码中。首次使用时：
  - 使用源代码：请先运行 `resource_manager.py` 生成配置文件。
  - 使用Release版本：请运行**资源管理器**，在最后一页填入你的 DeepSeek API Key 并生成配置文件。
- 目前自动情绪识别功能仅支持 DeepSeek API。

### 资源导入与配置

- **导入角色表情**：
  - 请将表情图片重命名为对应的情绪名称（如“开心.png”），以便API功能调用时自动匹配。
  - 若无自动情绪识别需求，可随意命名导入。
  - 若选择“自动”表情而API调用失败，程序将默认使用第一张表情，因此建议第一张表情尽量通用。
- **图片比例与调整**：
  - 表情图片建议使用瘦高或方形比例，程序会自动缩放，无需严格保持一致。
  - 如果同一角色的多张立绘导入后比例或位置不合适，请调整角色的 `enlarge`、`drawx`、`drawy` 参数，并**重新预生成**。
- **修改角色名字字体**：需要**删除该角色的预生成图片并重新预生成**。
- **背景图片**：
  - 会自动缩放，导入时需同时导入一个透明对话框遮罩（类似Galgame底部的对话框）。
  - 推荐透明框高宽比约为 131:640，大致符合即可。
- **GUI背景与图标**：
  - 可通过资源管理器导入，目前仅支持 960×540 的背景图像。
  - GUI图标也可通过资源管理器导入（暂不支持修改 `.exe` 文件本身的图标）。

### 功能限制

- 暂不支持**图像和文字一起转换**。
- LaTeX公式支持基于 latex 转 unicode，暂不支持复杂公式，且无法将 `\frac{}{}` 自动转换为 `/`。
- 部分英文字体可能不支持某些 unicode 公式符号，如需更换英文字体请谨慎测试。

### 快速上手（省流版）

1. 在 Release 版本的**资源管理器.exe**中，于“配置生成”栏填写 DeepSeek API Key，生成 `info.json`。
2. 运行 `星白对话框.exe`，从系统托盘打开窗口。
3. 选择角色，点击**预生成**，完成后保存设置。
4. 按默认热键 `Alt + Shift + A` 即可在 QQ、微信等场景中使用。
